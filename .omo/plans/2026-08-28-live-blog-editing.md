# Live Blog Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Executor model:** This plan is written for mid-level execution (Sonnet 4.6 / Kimi 2.7 Code). Every step has pseudocode — translate to real code, do not make architecture decisions.

**Goal:** Add password-protected admin UI at `/admin` that lets the single site owner create/edit/publish blog posts directly from the live site, persisted in Postgres, without redeploying. Legacy `.md` posts keep working.

**Architecture:** Convert Astro from pure static to hybrid mode (per-page `prerender = false`) using `@astrojs/netlify` adapter. Add Drizzle ORM over Postgres for `posts` + `sessions` tables. Blog list/detail/RSS become SSR, merge markdown collection with DB rows. Admin pages + API routes are SSR-only, protected by a middleware that checks a signed session cookie against the DB.

**Tech Stack:** Astro 7.x (hybrid), `@astrojs/netlify`, Drizzle ORM + `postgres` driver, `@paralleldrive/cuid2`, `bcryptjs`, `marked` + `isomorphic-dompurify`, `zod`, EasyMDE (CDN, no bundler).

**Project Conventions:**
- Framework: Astro 5+ content collections API — use `getCollection('blog')` + `render(entry)` from `astro:content` (NEW API, NOT `entry.render()`).
- Content collection entry `id` field is the slug (from `glob` loader). NOT `entry.slug`.
- Astro dynamic routes here use `[...slug].astro` (rest param), keep filename as-is when converting to SSR.
- Frontmatter for `.md`: `title`, `description`, `pubDate` (Date), `updatedDate?`, `heroImage?` (image() helper) — do NOT change schema.
- Layouts import `BaseHead`, `Header`, `Footer` — reuse for admin pages so styling stays consistent.
- Site constants live in `src/consts.ts` (`SITE_TITLE`, `SITE_DESCRIPTION`).
- No shadcn/ui, no Tailwind — plain Astro + scoped `<style>` per file. Follow existing scoped-style pattern in `BlogPost.astro` / `blog/index.astro`.
- Package manager: `npm` (per lockfile).
- Node: `>=22.12.0` (already pinned).

**Data Flow (write):**
```
[Admin browser] → POST /api/posts (multipart form)
  → middleware.ts checks session cookie → getSession() → sessions row
  → validators.ts (zod postSchema.parse)
  → slugExists(slug) — reject on collision
  → db.insert(posts).values(...)
  → 303 redirect /admin
```

**Data Flow (public read):**
```
[Visitor GET /blog]
  → prerender = false → SSR request
  → getAllPosts()
    ├─ getCollection('blog')  (markdown, static bundle)
    └─ db.select(posts).where(published = true)
  → merge + sort desc by pubDate
  → set Cache-Control: public, max-age=60, s-maxage=60
  → render list
```

**Data Flow (public detail):**
```
[Visitor GET /blog/my-slug]
  → prerender = false
  → getPostBySlug('my-slug')
    ├─ try markdown collection first (wins on collision)
    └─ fall back to db.select(posts).where(slug=? AND published=true)
  → null → Astro.rewrite('/404')
  → source === 'markdown' → render(entry) → <Content />
  → source === 'db' → markdownToSafeHtml(body) → <Fragment set:html>
```

**Constants:**

```

- [ ] **Step 1: Write helpers**

Pseudocode:
```
EXPORT const SESSION_COOKIE_NAME = 'session'
EXPORT const SESSION_MAX_AGE_SECONDS = 60 * 60 * 24 * 7

FUNCTION hashToken(raw: string): string
  RETURN createHash('sha256').update(raw).digest('hex')

EXPORT ASYNC FUNCTION createSession(cookies: AstroCookies): Promise<void>
  const rawToken = randomBytes(32).toString('base64url')          // 43 chars
  const tokenHash = hashToken(rawToken)
  const expiresAt = new Date(Date.now() + SESSION_MAX_AGE_SECONDS * 1000)

  AWAIT db.insert(sessions).values({ tokenHash, expiresAt })

  cookies.set(SESSION_COOKIE_NAME, rawToken, {
    httpOnly: true,
    secure:   import.meta.env.PROD,       // false in dev over http://
    sameSite: 'lax',
    path:     '/',
    maxAge:   SESSION_MAX_AGE_SECONDS,
  })

EXPORT ASYNC FUNCTION getSession(cookies: AstroCookies): Promise<Session | null>
  const raw = cookies.get(SESSION_COOKIE_NAME)?.value
  IF !raw: RETURN null

  const tokenHash = hashToken(raw)
  const now = new Date()

  const rows = AWAIT db.select().from(sessions)
    .where(and(eq(sessions.tokenHash, tokenHash), gt(sessions.expiresAt, now)))
    .limit(1)

  RETURN rows[0] ?? null

EXPORT ASYNC FUNCTION deleteSession(cookies: AstroCookies): Promise<void>
  const raw = cookies.get(SESSION_COOKIE_NAME)?.value
  IF raw:
    const tokenHash = hashToken(raw)
    AWAIT db.delete(sessions).where(eq(sessions.tokenHash, tokenHash))

  cookies.delete(SESSION_COOKIE_NAME, { path: '/' })
```

**Type contract:**

  slug:         string
  title:        string

  pubDate:      Date
  updatedDate?: Date
  heroImage?:   ImageMetadata       // only present when source === 'markdown'
  source:       'markdown' | 'db'

- [ ] **Step 1: Write file**

Pseudocode:
```
IMPORT { getCollection, type CollectionEntry } FROM 'astro:content'
IMPORT { eq, and, desc, ne } FROM 'drizzle-orm'
IMPORT { db } FROM '../db/client'
IMPORT { posts, type Post } FROM '../db/schema'

EXPORT type UnifiedPost = {
  slug: string
  title: string
  description: string
  pubDate: Date
  updatedDate?: Date
  heroImage?: any               // ImageMetadata from astro; keep loose to avoid Image() narrowing pain
  source: 'markdown' | 'db'
  body: string
  entry?: CollectionEntry<'blog'>
}

FUNCTION fromMarkdown(entry: CollectionEntry<'blog'>): UnifiedPost
  RETURN {
    slug: entry.id,                                   // NOTE: glob loader → id is the slug
    title: entry.data.title,
    description: entry.data.description,
    pubDate: entry.data.pubDate,
    updatedDate: entry.data.updatedDate,
    heroImage: entry.data.heroImage,
    source: 'markdown',
    body: entry.body ?? '',
    entry,
  }

FUNCTION fromDbRow(row: Post): UnifiedPost
  RETURN {
    slug: row.slug,
    title: row.title,
    description: row.description,
    pubDate: row.pubDate,
    updatedDate: row.updatedDate ?? undefined,
    heroImage: undefined,
    source: 'db',
    body: row.body,
  }

EXPORT ASYNC FUNCTION getAllPosts(): Promise<UnifiedPost[]>
  const [mdEntries, dbRows] = AWAIT Promise.all([
    getCollection('blog'),
    db.select().from(posts)
      .where(eq(posts.published, true))
      .orderBy(desc(posts.pubDate)),
  ])

  const merged: UnifiedPost[] = [...mdEntries.map(fromMarkdown), ...dbRows.map(fromDbRow)]

  RETURN merged.sort((a, b) => b.pubDate.valueOf() - a.pubDate.valueOf())

EXPORT ASYNC FUNCTION getPostBySlug(slug: string): Promise<UnifiedPost | null>
  // Try markdown first — legacy wins on collision.
  const mdEntries = AWAIT getCollection('blog', (e) => e.id === slug)
  IF mdEntries.length > 0: RETURN fromMarkdown(mdEntries[0])

  const rows = AWAIT db.select().from(posts)
    .where(and(eq(posts.slug, slug), eq(posts.published, true)))
    .limit(1)
  IF rows[0]: RETURN fromDbRow(rows[0])

  RETURN null

EXPORT ASYNC FUNCTION slugExists(slug: string, excludeId?: string): Promise<boolean>
  // Check .md collection.
  const mdEntries = AWAIT getCollection('blog', (e) => e.id === slug)
  IF mdEntries.length > 0: RETURN true
